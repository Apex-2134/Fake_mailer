# Simple Python Email Sender

A lightweight, automated email sender script written in Python using standard libraries (`smtplib` and `email.mime`). Created for educational and learning purposes.

---

## 📌 Features
* Sends custom text emails directly to any valid email address.
* Built with core Python modules without requiring third-party dependencies.
* Simple terminal interface for interactive input.

---
